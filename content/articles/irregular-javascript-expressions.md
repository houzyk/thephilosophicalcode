> [The MDN reference on JavaScript regular expressions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Regular_expressions "The MDN reference on JavaScript regular expressions") states that "JavaScript regular expressions are in fact not regular". This highlights a subtle tension between actual regular expressions and their implementation in JavaScript. In this article, we'll examine this tension by exploring the theory behind regular expressions, cashing out the tension as an issue of computational expressivity and showing how backreferences make JavaScript regular expressions irregular.
